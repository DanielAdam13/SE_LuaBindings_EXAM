# LuaBindingGameEngine
A project practicing Lua bindings with C++ using SOL2.

There are two parts of this project:

1. PROJECT - Binding/Linking functionality from the given Engine in:
 - EngineLuaBindings
and showing AbstractGame functions to the Game via:
 - LuaGame

2. GAME - A program made using the available bounded functions from SOL2 where:
 - main.cpp : displays the window and calls the runtime dependency main.lua
 - main.lua and annotations.lua : actual Game logic written in Lua scripting language
